## Pull request acknowledgement

Pull requests should use the repository pull request template and confirm that the contributor has read and agrees to these contribution terms. Do not submit a Contribution if you cannot make that confirmation.

## Development expectations

- Keep diagnostic claims traceable to evidence.
- Do not present simulated evidence as measured evidence.
- Prefer deterministic behaviour for diagnostic findings.
- Add or update tests for behavioural changes.
- Run `npm run check` and `npm test` before requesting review when practical.
- Do not include credentials, private customer information, packet payloads, or other sensitive material in commits or fixtures.
