    Fixed reference incidents covering known failure classes. Selecting one loads it into the analysis above so the reasoning can be inspected without an active fault. Real measurements come from Live Diagnostics.

    Continuous low-rate capture so a fault that lasts ten seconds still leaves evidence. Answers the question a one-shot diagnostic cannot: what was happening in the seconds before it broke?

    Local topology inferred from routing, adapter and neighbour evidence, extended with observed public hops. Inferred relationships are drawn differently from observed ones — Faultline does not claim topology it did not measure.

    A case holds every run, contract result and artefact for one investigation, so the evidence stays attached to the question it was collected to answer.

    Portable evidence packages and cross-incident pattern analysis. Similarity and clustering are a separate evidence class from deterministic diagnosis and are labelled as such wherever they appear.
