Faultline will collect

  • gateway latency and packet loss
  • DNS, TCP, HTTP and route test results
  • application connectivity-condition results when a Connectivity Contract is attached
  • active network adapter and VPN state
  • Wi-Fi signal and access-point metadata when available

Faultline will not collect

  • packet payload contents
  • browser or search history
  • files or documents
  • passwords or account credentials
  • application messages or call contents
